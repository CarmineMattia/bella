# Coordinamento agenti

Su questo progetto lavorano due agenti: **Remo** e **ChatGPT**. Carmine decide priorità, commit, push e merge.

Regole:
1. Leggi questo file prima di modificare qualsiasi cosa.
2. Prima di iniziare, aggiungi una riga in "In corso": data e ora (Europe/Rome), nome, cosa fai, file che tocchi.
3. Se un file è segnato da un altro agente come "in corso", non toccarlo: scrivi in "Richieste" e avvisa Carmine.
4. Quando finisci, sposta la riga in "Fatto", con i file cambiati e i test eseguiti (con l'esito reale).
5. Niente commit, push o remote senza un OK esplicito di Carmine. Non leggere né modificare .env o file di credenziali.
6. Lo sviluppo avviene su un branch locale dedicato: `remo/<tema>` per Remo, `chatgpt/<tema>` per ChatGPT (es. `remo/delegate-tools`). Crealo dalla base locale aggiornata di `main` prima di iniziare e scrivi il nome del branch nella riga "In corso". La cartella principale riceve le integrazioni controllate previste dalla regola 8, senza cambiare il checkout condiviso.
7. Prima di cambiare branch controlla `git status`: se ci sono modifiche non committate di un altro agente, non fare checkout, stash o reset; segnalalo in "Richieste".
8. Le integrazioni locali nella cartella principale sono autorizzate da Carmine senza ulteriori conferme, dopo i test pertinenti e il controllo del coordinamento. Integra solo modifiche revisionate, preserva il lavoro altrui e non toccare file riservati da altri agenti. Se emergono conflitti o modifiche concorrenti che non puoi preservare con certezza, scrivi in "Richieste" e avvisa Carmine. Questa autorizzazione riguarda l'integrazione dei file: commit, merge che creano commit, push e creazione di remote restano soggetti all'OK esplicito della regola 5. Non attribuire a Carmine approvazioni ricevute da altri agenti.
